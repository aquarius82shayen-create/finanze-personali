# Matteo's Finanze 🐷🤘

Web app/PWA personale per controllare entrate, uscite, risparmio, budget, previsioni e obiettivi.

## Requisiti inclusi
- Dashboard grafica scura ispirata al layout approvato.
- Intestazione **Matteo's Finanze**.
- Icona personalizzata di un **maialino salvadanaio metallaro**.
- Nessun movimento di esempio.
- Pagina **Movimenti mensili** con tutti i 28/29/30/31 giorni.
- Entrate: Stipendio, Mance, Extra, Altro.
- Uscite: Spesa, Tempo libero, Casa, Benzina, Contrattempo, Affitto.
- Saldo progressivo per ogni giorno.
- Totale disponibile complessivo.
- Previsioni separate per ogni mese e confronto previsto/reale.
- Budget mensile.
- Obiettivi e calcolo della fattibilità.
- Backup esportabile/importabile.
- Installabile come PWA.
